# Duchess Virelai starter avatar (schemer)

Flat vector bust emblem for the shipped starter trope pack (T184): gold spike crown over swept plum hair, high collar, court rings.

Fully own-generated: drawn from primitive geometry (circles, rects, triangles, arcs, capsules) by `generate.py` in this directory — pure Python, no image model, no third-party art. The PNG is a build artifact of that script plus the per-persona palette in `packages/personas/starter-pack/src/tropes.ts`; regenerate in place with `python generate.py`.
