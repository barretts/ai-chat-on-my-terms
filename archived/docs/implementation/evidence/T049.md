# T049 — Complete chat integration progress

Date: 2026-09-26. Features: ER-03, ER-04, ER-05. State: running.

## Mounted behavior

`apps/mobile/app/chat.tsx` mounts `composition/chat/screen.tsx`. It shares SQLite history,
managed blobs, saved provider selection, scoped settings, composer preferences, attachment
intake, archive ports, local search, and generation lifecycle state.

- Library, settings, search, archives, and provider setup open from chat. Saved conversations
  reopen in the same engine projection; creating a conversation allocates a fresh identity.
- Provider selection is persisted per conversation. The factory binds the exact connection
  and model, applies explicit HTTP LAN authorization, resolves host-scoped secret references,
  and redacts failures before the engine writes them to SQLite.
- The advanced engine sends canonical provider roles, uses selected saved variants, counts
  pending attachment context, applies saved settings/system prompts, and regenerates the
  original user turn without inserting a second user message.
- Reopening a fallback chat restores its last exact saved model/connection. Imported assistant
  rows render from durable parts, while running replies retain live projection updates. The
  composer stays mounted when panels open, and send preflight guards navigation and model changes.
- Native file intake copies originals into managed storage. UTF-8 documents are extracted;
  image payloads are gated by verified vision capability, MIME type, and byte limits.
  Failed extraction keeps the original descriptor and bytes for recovery.
- ZIP import/export preserves variants and assets with fresh imported identities. ZIP entries
  are bounded and checked for traversal, duplicates, truncation, and CRC. TXT/PDF sharing
  uses actual Expo file, print, and sharing ports.
- Search resolves source links against selected visible variants. Semantic indexing has a
  global selected-text snapshot so rebuilding one chat preserves other chats.
- Remote HTTP streams without durable job IDs stop and become interrupted on suspension.
  Durable remote jobs remain pending for later reconciliation.
- Core stops persist cancellation even before stream consumption. Early closure and feature
  callback failures preserve partial output and settle lifecycle/index hooks. Secondary feature
  failures preserve completed generation status and use a separate recovery message.
