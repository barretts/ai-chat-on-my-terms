Support

For help with AI Chat on My Terms, email barrett@sosuke.com.

Include your app version, device model, iOS version, and steps to reproduce the problem. If a model or connection is involved, include its name and the error message. Remove personal information before sending screenshots or logs. Never send API keys, passwords, recovery secrets, or private chat histories.

On-device chat

Check available storage and choose a model supported by your device. A model must finish downloading before it can run without a network connection. Larger models can require more memory than your device has available.

Connecting to your server

Make sure the phone can reach your server and that the endpoint and model name are correct. A server on a private home network is normally available only while the phone has access to that network.

Cloud providers

Check your provider credentials, API access, and balance with that provider. Provider charges and outages are separate from this app. AI responses may be inaccurate; verify important information.

Data and deletion

Delete conversations from the app when you no longer need them. Exports, shared files, backups, and provider-side records are separate copies and must be managed at their respective destinations. Contact us for questions about information you have sent to support.
