- `modules/gguf/ios/` only if lease hooks are needed

**Implementation steps**
1. Room runtime holds ONE binding: the room's `sharedModelId` (T170) resolved to an installed managed model; participants never bind their own models in v1 group rooms (per-seat `providerConnectionId+modelId` stays for compat but the group runtime ignores it when a shared binding exists — comment this clearly).
2. Serialize ALL generation traffic for the room through one slot: persona replies AND the topic-interest selector call from T173 share one `ModelLeaseRegistry` with host capacity 1 for the local model key. Reuse the existing FIFO/abort behavior; do not add a second scheduler.
3. The model stays loaded between replies (reference-counted `ModelFileLease`); each request rebuilds its complete prompt from scratch (turns port contract already does) so persona instructions cannot carry over — add an invariant test: two consecutive requests to different speakers share no message objects.
4. Release triggers: app backgrounding (RN AppState → `ShortBackgroundExecution` grace then release), leaving the room screen, model change (T175's picker), and memory-pressure signal if the native bridge exposes one; release = drop all leases for the room's model key after in-flight run settles or cancels.
5. Isolated failure policy: a single speaker generation error marks that `group_runs` row `failed` and continues the round (per plan fallbacks); loading/lease failure aborts the whole round with an actionable error and NO silent model substitution.
