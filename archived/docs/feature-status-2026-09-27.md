# LocalLab feature status — September 27, 2026

This inventory describes the current app and its remaining work. It was checked against mounted routes, chat composition, implementation evidence, and the roadmap. Package code, usable app workflows, and physical device verification are separate completion levels.

## September 28 messenger update

The current source adds a Windows 98 / Yahoo Messenger inspired purple title bar, teal desktop, beveled controls, taskbar navigation, light/dark appearance and reduced-motion-aware activity animations. Phone chat controls are smaller, writing options open in a separate dialog, model reasoning collapses, and iOS gets keyboard avoidance. Compact chrome keeps the composer above the taskbar on short screens; the actual 320×568, 390×844 and 440×956 browser layouts passed, along with two first-run phone UI cases. Native keyboard handling still needs an iPhone run.

Providers now form a searchable saved address book with edit, favorite, remove and selection controls. The searchable Chat model dropdown queries the configured endpoint. Voice Studio has a voice dropdown, persisted speed controls, and Persona voice/speed bindings (parts of PE-07, PE-08, VO-05 and VO-13).

Large model SHA scans are skipped by request. Downloads retain size checks and a small GGUF header check. Native voice downloads use foreground sessions, a storage-space check and an explicit unpacking phase. These native fixes are an attempt pending an iPhone run. Browser voice repair updates its small runtime without reading or downloading the cached model weights.

Current evidence: real OxCoder endpoint discovery and generation; saved-provider CRUD, favorites, model selection and reload; genuine OpenRouter catalog search; appearance and voice/Persona preferences after reload; all three voices generated real audio offline using existing packs; 1.3× shortened both Kokoro and Piper audio; 22 targeted provider/storage tests and 3 OpenRouter phone-sized browser fixture cases passed. The [messenger evidence](implementation/evidence/messenger-ui-2026-09-28.md) records scope and receipts. These changes are newer than signed iPhone build 3. The [Mac/iPhone debugging guide](../../docs/iphone-local-debugging.md) describes the native verification path.
