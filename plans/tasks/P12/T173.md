**Implementation steps**
1. Order policies, all producing a frozen permutation of seat indices stored on the round (T170 `group_rounds.frozen_order_json`):
   - `round-robin`: seating order, rotating start after each completed round.
   - `dice`: shuffled permutation (Fisher-Yates, seeded per round for replayability) saved with the round.
   - `topic-interest`: ONE short structured request to the shared model: prompt lists every seat id/name/scenario + the user's latest text, `json_object` response `{scores:[{seat,score}]}`; validate strictly — every seat exactly once, scores numeric; sort desc, tie-break by seating; any invalidity (missing/duplicate/invented seats, unparseable) → seat-order fallback, NO retry calls. Add a source comment preserving the future idea: participants could abstain (`// Future: let participants abstain via a score floor instead of always speaking.`).
2. Context modes: `discussion` = later speakers see earlier completed replies (already the turn transcript shape); `independent` = every speaker receives the same frozen starting transcript; the round record notes the mode.
3. `Pass` = `planGroupUserTurn` with `userText` undefined → no user message inserted; disable Pass before a conversation has any content. `Ask(seatIndex)` already planned (`askSeatIndex` :36) — wire to the engine assistant path from T172.
4. Drunk recall in the group context builder (apps-side, before compaction): when a participant has `drunk:true`, their view of prior history is truncated to ≈512 estimated tokens (`length/4` estimate) favoring the most recent messages, KEEPING persona instructions, room instructions (scenario), and the current user message; messages with `compacted:true` are excluded entirely; never summarize the dropped history back in. Stored history untouched; toggling Drunk off restores full access. Do not touch `packContext`'s native allocation.
5. Freeze discipline: speaker identity/instructions are snapshotted into `GroupTurnSpeaker` at round start (existing GR-05..08 tests) — persona edits mid-round must not leak (add regression test).
