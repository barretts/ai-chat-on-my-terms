3. Chat header: same fallback chain at :2615-2631 (photo replaces initials circle; initials remain fallback).
4. Group transcript + participant controls (T175 surfaces) resolve avatars through the same helper; avatars NEVER enter model prompts (assert in a test: context builder output contains no attachment ids for avatars); missing image files fall back without blocking chat (existing persona missing-photo notice pattern :676-679).

6. Accessibility: avatar images get the participant/conversation name as label; decorative duplicates (list row next to visible name) marked hidden.
